# Известувања за промена на цена

Посетител може да побара е-пошта кога ќе се смени цената или планот на алатка.
Функцијата е **исклучена** додека не поставиш сервис за праќање е-пошта.

## Како работи

1. Посетителот ја внесува е-поштата на профилот на алатката („Извести ме кога ќе се смени
   цената“) и дава согласност.
2. Добива е-пошта за потврда (двојна потврда, *double opt-in*). Следењето е активно дури
   по кликот на линкот и копчето „Потврди“.
3. Кога уредник ќе кликне **„Означи проверено“** на алатката, системот ги собира
   промените на цената/планот од претходната проверка и праќа по **една** порака на секој
   активен следач. Непроверени измени никогаш не праќаат известувања.
4. Секоја порака има линк за одјава (и `List-Unsubscribe` заглавие).

Линковите за потврда и одјава се потпишани (HMAC) — во базата не се чуваат лозинки ни
токени за потврда; токените стојат во редот за праќање само додека пораката не замине.

## Поставување

1. Отвори сметка кај [Resend](https://resend.com) (или прилагоди ја функцијата за друг
   сервис), потврди го доменот и креирај API клуч.
2. Тајни и објава на функцијата:

```bash
supabase secrets set RESEND_API_KEY=... EMAIL_FROM="AI KATALOG <izvestuvanja@tvojdomen.mk>" \
  SITE_URL=https://www.tvojdomen.mk CRON_SECRET=$(openssl rand -hex 32)
supabase functions deploy send-notifications --no-verify-jwt
```

3. Закажи праќање на секои 10 минути (Supabase → Database → Extensions: вклучи `pg_cron`
   и `pg_net`, потоа во SQL Editor):

```sql
select cron.schedule('send-notifications', '*/10 * * * *', $$
  select net.http_post(
    url := 'https://<ref>.supabase.co/functions/v1/send-notifications',
    headers := jsonb_build_object('x-cron-secret', '<CRON_SECRET>')
  );
$$);
```

4. Во Vercel постави `VITE_FEATURE_ALERTS=1` и изгради го сајтот повторно — дури тогаш
   формуларот се појавува на профилите.
5. Админ → **Известувања** (само за администратори) покажува колку пораки чекаат, колку се
   испратени и кои не успеале.

Неуспешно праќање се повторува до 3 пати; пораките „заглавени“ подолго од 15 минути
повторно се преземаат.
