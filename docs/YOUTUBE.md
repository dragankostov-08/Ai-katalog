# Видео туторијали од YouTube

Секоја алатка може да има листа рачно одбрани YouTube туторијали. Тие се прикажуваат
на профилот на алатката во делот „Видео туторијали“.

## Како работи

- **Уредникот одлучува.** Во админ → алатка → „Видео туторијали“ можеш:
  - да залепиш YouTube линк (`watch`, `youtu.be`, `shorts`, `embed`);
  - да пребараш на YouTube (македонски, регионални или англиски туторијали) и да кликнеш „Додај“ кај видеото што го одбра.
  Ништо пронајдено преку API не се објавува автоматски.
- За секое видео бираш јазик (на македонски / регионален / англиски), јавна белешка
  (на пр. „Добро за почетници“), редослед и дали е видливо.
- **„Провери достапност“** ги освежува насловите и времетраењето и автоматски ги
  крие видеата што се избришани или приватни.
- **Приватност на посетителите:** на јавната страница ништо не се вчитува од YouTube додека
  посетителот не кликне „пушти“. Видеото потоа се вчитува од `youtube-nocookie.com`.

## Без API клуч

Функцијата работи и без YouTube API: кога ќе залепиш линк, внесуваш наслов и канал
рачно. Пребарувањето и автоматското пополнување бараат клуч.

## Поставување на YouTube Data API (незадолжително)

1. Google Cloud Console → нов проект → **APIs & Services → Library** → вклучи
   **YouTube Data API v3**.
2. **Credentials → Create credentials → API key**. Под *API restrictions* ограничи го
   клучот само на YouTube Data API v3.
3. Внеси го клучот како тајна на Supabase и објави ја функцијата:

```bash
supabase secrets set YOUTUBE_API_KEY=твојот-клуч
supabase functions deploy youtube
```

Клучот останува на серверот (Edge Function `supabase/functions/youtube`). Никогаш не
го ставај во `VITE_` променлива. Функцијата ја повикуваат само најавени уредници:
проверува `is_staff()` и не запишува ништо во базата.

## Квота и правила

- Бесплатната дневна квота е 10.000 единици. Едно пребарување троши 100 единици
  (≈100 пребарувања дневно), а проверката на достапност троши 1 единица за до 50 видеа.
- Со користење на API ги прифаќаш *YouTube API Services Terms of Service* и *Developer
  Policies*. Тие ограничуваат колку долго смее да се чуваат податоците добиени од API
  (наслови, канали) без освежување. Затоа користи „Провери достапност“ редовно (на пр.
  еднаш месечно) и прочитај ги актуелните правила пред лансирање.
- Видеата се туѓа содржина: прикажи ги само преку вградениот плеер или линк до YouTube,
  без преземање и повторно објавување.
