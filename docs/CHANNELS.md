# Канали: Viber, Telegram, социјални мрежи

## Линкови во подножјето

Админ → **Поставки**: внеси ги целосните `https://` линкови до Viber каналот, Telegram
каналот, Instagram, Facebook, TikTok, YouTube и LinkedIn. Се прикажуваат во подножјето на
сајтот по следното градење (празно поле = не се прикажува).

## Неделен преглед

Админ → **Неделен преглед** автоматски составува преглед на новото за последните 7, 14
или 30 дена: нови алатки, *потврдени* промени на цени, водичи, споредби, промптови,
тестови на македонски, патеки и поими. Добиваш:

- **обичен текст** за Viber и Telegram — копче „Копирај“;
- **HTML** за алатката за билтен — копче „Копирај HTML“.

Прочитај го текстот пред објавување.

## Автоматско објавување на Telegram (незадолжително)

1. Во Telegram, кај [@BotFather](https://t.me/BotFather) креирај бот и земи го токенот.
2. Додај го ботот како администратор на твојот канал.
3. Постави ги тајните и објави ја функцијата:

```bash
supabase secrets set TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=@imenakanal
supabase functions deploy telegram-post
```

4. Во „Неделен преглед“ кликни **„Објави на Telegram“**. Функцијата ја повикуваат само
   најавени уредници; долгите прегледи се делат на повеќе пораки.

Viber каналите немаат едноставен јавен API за објавување, затоа за Viber користи копирање
и лепење.
